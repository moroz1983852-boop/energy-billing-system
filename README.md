# ⚡ Java Energy Billing System

Ein Backend- und Frontend-System auf Basis von Java (Spring Boot) zur Berechnung und Verwaltung von Stromabrechnungen, Zählerständen und Tarifen.

## 🛠 Technologiestack

* **Sprache:** Java 17+
* **Framework:** Spring Boot
* **Build-Tool:** Maven (Maven Wrapper `./mvnw`)
* **Frontend:** HTML5, CSS3, JavaScript
* **Architektur:** REST API (Controller, Service, Repository, Model)

## 🚀 Hauptfunktionen

* 📊 **Erfassung von Zählerständen:** Eingabe und Berechnung des Stromverbrauchs.
* 💳 **Abrechnung & Tarife:** Automatische Berechnung der Rechnungen auf Basis aktueller Tarife.
* 👤 **Kundenverwaltung:** Übersicht und Steuerung von Kundendaten.
* 🌐 **Web-Interface:** Benutzeroberfläche zur Anzeige von Kunden und Rechnungen im Browser.
